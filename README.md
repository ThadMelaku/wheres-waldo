# Where's Waldo?

A photo-tagging game built as part of The Odin Project

## Features

- Interactive photo tagging with server-side validation
- Progress tracking and game timer
- Top 10 leaderboard with saved scores
- Responsive layout with sticky sidebar

## Built With

- React + Vite
- JavaScript
- Express.js
- SQLite
- CSS

## Live Demo

[Play Where's Waldo](https://wheres-waldo-production-9633db99.up.railway.app/)

## Getting Started

Install dependencies:

```bash
npm install
npm --prefix server install
```

Start the backend:

```bash
cd server
node index.js
```

In a separate terminal, start the frontend:

```bash
npm run dev
```
